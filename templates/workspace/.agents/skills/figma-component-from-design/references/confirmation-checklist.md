# 组件确认清单

只询问当前设计真正适用的项目。

## 结构

- 源节点与目标范围。
- 组件名称。
- 单组件、组件集或嵌套组件。
- 固定、内容自适应、填充、换行和最小或最大尺寸。
- 同尺寸不同状态是否保持相同宽高。

## 属性与变体

- 文本：标签、数值、辅助文字、占位文字。
- 布尔：图标、徽标、分隔线、加载指示和关闭按钮。
- Instance Swap：前置图标、后置图标、头像、图片和操作插槽。
- Variant：状态、尺寸、语义色、密度、方向和主题。
- 每个 Variant 轴的有限值集合，以及哪些实际 Instance 使用每个组合。

## 抽象边界

- 语义职责、实体、操作、权限与状态集合是否一致。
- 结构签名是否一致；仅视觉相似时标记为 `primitive-only`，不合并业务组件。
- 每个候选节点的决定：`shared-component`、`primitive-only` 或 `local-structure`。
- 公共部分变化时，哪些实例应该同步变化，哪些实例必须保持不变。
- 是否存在页面名、路由、特殊间距或一次性布尔开关；存在时先调整抽象边界。

## Lit 交接

- Figma 属性 → Lit Property / Attribute。
- Instance Swap 或内容区域 → 命名 Slot。
- 交互 → 已声明 Event。
- 每个使用中 Figma Variant → Lit Attribute 值。

## 变量

- 颜色、排版、间距、圆角、描边、阴影、尺寸和主题模式。
- 复用已有库变量，还是创建项目本地变量。

## 建议确认格式

```text
请确认：
1. 组件名：...
2. 结构：...
3. 变体：...
4. 属性：...
5. 变量与复用来源：...
6. 抽象决定：共享组件 / Primitive / 局部结构及依据...
7. Lit 交接：属性、事件、插槽和 CSS 变量...
8. Variant 覆盖：Figma Instance → Lit Attribute...
```
